# ☕ TipJar — On-Chain Tip Jar

> **MetaMask Community Builder Challenge Pune** · Problem: The Thank-You Wall

A transparent, permissionless tip jar on **Ethereum Sepolia**. Readers connect a wallet, send a micro-tip with a short message, and watch their name appear on a live, on-chain supporter wall — no middleman, no cut, no geo-blocks.

## 🚀 Setup & Deployment

### Prerequisites

- Node.js ≥ 18
- A MetaMask wallet
- Sepolia ETH (free from faucets)

### 1. Clone & Install

```bash
git clone <your-repo-url>
cd tipjar
npm install
```

### 2. Configure Environment

```bash
cp .env.example .env
```

Edit `.env`:

```env
# Get a free Sepolia endpoint at https://www.quicknode.com
QUICKNODE_SEPOLIA_URL=https://...

# Burner wallet private key (fund from faucet, NOT your main wallet)
PRIVATE_KEY=0x...

# Optional: verify source on Etherscan
ETHERSCAN_API_KEY=
```

### 3. Get Test ETH

Fund your burner wallet from a Sepolia faucet:

- <https://sepoliafaucet.com>
- <https://faucet.quicknode.com/ethereum/sepolia>
- <https://faucets.chain.link>

### 4. Compile & Test

```bash
npm run compile   # Compile TipJar.sol
npm test          # Run unit tests (Hardhat)
```

### 5. Deploy to Sepolia

```bash
npm run deploy:sepolia
```

This will:
- Deploy `TipJar.sol` to Sepolia
- Print the contract address
- Save `frontend/contract-address.json` and `frontend/TipJarABI.json`

### 6. Run the Frontend

```bash
# Simplest — open directly
open frontend/index.html   # macOS
start frontend\index.html  # Windows

# Or serve locally
npx serve frontend
```

## 🧱 Contract API

```solidity
// Send a tip with an optional message (≤ 280 chars)
function tip(string calldata message) external payable

// Withdraw all ETH to owner (onlyOwner)
function withdraw() external

// Read stats
function totalTips()   external view returns (uint256)
function totalAmount() external view returns (uint256)
function getBalance()  external view returns (uint256)

// Emitted on every tip
event NewTip(
    address indexed sender,
    uint256 amount,
    string  message,
    uint256 timestamp
);
```

## 🔒 Security Notes

- **Burner wallet only** — never put your main MetaMask seed into `.env`
- `.env` is in `.gitignore` — never commit it
- Contract uses custom errors (gas-efficient)
- Plain ETH transfers (`receive()`) revert with a helpful message — use `tip()`
